图_2文档入库模块 · 详细实现

对应 [[2_代码实现_文档入库]]。保留全部文件、类与逐函数分步内容。

读图方式

  1. 蓝底是文件，紫底是类，灰底是函数；框宽按文字自适应，标题与分步文本分开。
  2. 每个函数 / 类有唯一编号，例如 F01 / C01；步骤末尾 〔→ F07〕 表示调用或依赖对应编号。P 编号表示文件；P02:3 精确定位到 P02 文件的第 3 步，F04:2 定位函数 F04 的第 2 步。
  3. 只有相邻、能在文件内短距离连接且不穿越文字 / 其他函数框的关系画曲线。其余保留编号引用。重复使用的公共助手不再扇出多条长线。
  4. 编号仅用于查找，不表示全局执行顺序；每个框里的 1、2、3 才是该框的执行步骤。总图另有问答与入库主链。

文件与函数索引

P01 · backend/indexing/document_loader.py

统一多格式加载并生成三级 Chunk。

  • F01 sanitize_text()（源码 16 行）：清洗待索引的字符串。
  • F02 DocumentLoader.__init__()（源码 54 行）：按输入参数建立三层递归分块器。
  • F03 DocumentLoader.load_documents_from_folder()（源码 222 行）：遍历文件夹并累积支持格式的 Chunk。
  • F04 DocumentLoader.load_document()（源码 195 行）：按扩展名选择加载分支。
  • F05 DocumentLoader._load_from_langchain_docs()（源码 162 行）：统一来源元数据并逐页调用分块。
  • F06 DocumentLoader._split_page_to_three_levels()（源码 85 行）：在当前页内嵌套生成 L1 / L2 / L3。
  • F07 DocumentLoader._build_chunk_id()（源码 82 行）：构造页内层级 Chunk 的确定性 ID。
  • C01 DocumentLoader：持有三个分块器，统一不同格式输出。

P02 · backend/indexing/html_processor.py

把 HTML 正文转为有章节页码的 Document。

  • F08 load_html_for_document_loader()（源码 152 行）：将网页章节封装为统一加载器输入。
  • F09 parse_html_file_to_sections()（源码 139 行）：编排编码识别、正文提取和章节切分。
  • F10 _read_html_text()（源码 21 行）：按 BOM、charset 和回退顺序解码。
  • F11 _strip_noise()（源码 41 行）：就地移除 HTML 非正文噪声。
  • F12 _pick_root()（源码 48 行）：选择优先级最高的正文根节点。
  • F13 _doc_title()（源码 108 行）：提取页面 title 字符串。
  • F14 _br_to_newlines()（源码 52 行）：保留显式换行标签的含义。
  • F15 _linearize_blocks()（源码 57 行）：按语义块生成较稳定的正文文本。
  • F16 _split_into_sections()（源码 115 行）：按二级标题拆成虚拟页面。

P03 · backend/indexing/embedding.py

为入库和 Query 复用同一个本地 Dense 模型。

  • F17 _create_dense_embedder()（源码 6 行）：根据配置创建归一化 Dense 编码器。
  • F18 EmbeddingService.__init__()（源码 19 行）：持有一个本地 Dense 编码器。
  • F19 EmbeddingService.get_embeddings()（源码 22 行）：批量编码文本列表。
  • C02 EmbeddingService：向调用方暴露统一批量编码方法。

P04 · backend/indexing/milvus_writer.py

把调用方选出的 L3 Chunk 批量编码入库。

  • F20 MilvusWriter.__init__()（源码 11 行）：注入或复用向量服务与 Store。
  • F21 MilvusWriter.write_documents()（源码 15 行）：按批次编码并写入完整叶块记录。
  • C03 MilvusWriter：只负责编码和写入，父块保存由调用方负责。

F06 _split_page_to_three_levels()：在当前页内嵌套生成 L1 / L2 / L3 ^c28e1bf1

  1. 空正文直接返回 []；读取页码与来源，重置本页各层计数。 ^ffc81f0a

  2. L1 splitter 切页内正文；非空 L1 生成 ID，parent 为空、root 指向自己。 ^c9daf0f3

  3. 每个 L1 再切 L2；L2 的 parent 指向当前 L1，root 仍为 L1。 ^aa31e43c

  4. 每个 L2 再切 L3；L3 的 parent 指向当前 L2，root 指向所属 L1。 ^d8e62e4a

  5. 每层调用 _build_chunk_id()，保存正文 / 层级 / 全局 chunk_idx；返回三层混合 列表。 〔→ F07〕 ^b5507877

F07 _build_chunk_id()：构造页内层级 Chunk 的确定性 ID ^4d3b3e51

  1. 按 filename::p页码::l层级::层内序号 拼接字符串。 ^6d4bed78

  2. 层内序号由当前页相应层级的计数器提供。 ^dacc6448

F21 write_documents()：按批次编码并写入完整叶块记录 ^ca597f65

F08 load_html_for_document_loader()：将网页章节封装为统一加载器输入 ^186f92b2

F09 parse_html_file_to_sections()：编排编码识别、正文提取和章节切分 ^6d3e2ecc

  1. Path() 规范路径，_read_html_text() 读取字符串，BeautifulSoup 解析 HTML。 〔→ F10〕 ^42648c05

  3. 调用 _linearize_blocks() 得到线性文本；有标题且正文未以标题开头时补 h1。 〔→ F15〕 ^202118bc

  4. 交给 _split_into_sections() 返回带 page / title / text 的章节列表。 〔→ F16〕 ^3df13981

F10 _read_html_text()：按 BOM、charset 和回退顺序解码 ^906a4668

  1. 读取原始 bytes；UTF-8 BOM 存在时剥离并直接按 UTF-8 解码。 ^8f6c1ec2

  2. 从前 8192 字节搜索 charset；规范 utf8 别名并尝试指定编码。 ^230fcbbc

  3. 指定编码不可用或解码失败时尝试 UTF-8。 ^8072e67e

  4. UTF-8 仍失败则用 GB18030，无法识别字符替换处理。 ^0fcb7be3

F11 _strip_noise()：就地移除 HTML 非正文噪声 ^58019fb1

  1. 删除 script / style / noscript / template / iframe / svg 节点。 ^1783dc82

  2. 找出 Comment 并 extract() 移除；在原 soup 上修改，不返回新树。 ^ce482e1c

F12 _pick_root()：选择优先级最高的正文根节点 ^76ec0ec3

  1. 依次尝试 main → article → body。 ^e11919d7

  2. 都不存在时退回整个 soup。 ^7ea22f88

F13 _doc_title()：提取页面 title 字符串 ^6809dee6

  1. 查找 title 节点，且其 .string 存在时返回 strip() 后的标题。 ^ca9686df

  2. 否则返回空字符串。 ^3c9b26c7

F15 _linearize_blocks()：按语义块生成较稳定的正文文本 ^6d5d9b8a

  1. 先调用 _br_to_newlines()。 〔→ F14〕 ^d5002235

  2. 按文档顺序读取最多 8000 个标题 / 段落 / 列表 / 单元格等块，跳过空文本。 ^652e8e38

  3. h1～h4 加 Markdown 标题前缀，其他块直接收集，合成为 structured。 ^82644fae

  4. 同时取 plain；structured 缺失或明显过短（不足 max(120, plain×0.22)）时回 退 plain。 ^3b333911

  5. 返回选出的结构化文本或纯文本。 ^523b21f0

F14 _br_to_newlines()：保留显式换行标签的含义 ^de5aa6f9

  1. 遍历根节点下的 br。 ^65b54933

  2. 逐个替换为换行字符，直接修改节点树。 ^f09852f1

F16 _split_into_sections()：按二级标题拆成虚拟页面 ^0edd8c0b

  1. strip() 后为空则返回 []；按行首 ## 标题分段并去空段。 ^1d71d76e

  2. 不足两段时返回单页，page=1，可在正文前加网页标题。 ^cdbc7646

  3. 多段时从 1 编页码，提取首行标题，加章节前缀。 ^5e4c8233

  4. 返回每段的 page / title / text，供 HTML Document 的 metadata.page 使用。 ^9e5eb01d
