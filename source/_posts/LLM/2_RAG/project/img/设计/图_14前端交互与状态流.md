# 图_14前端交互与状态流

原生 Excalidraw 可编辑画布，基于 SuperMew-0.1.0。请使用 Obsidian 的 Excalidraw 视图打开。

**所属模块：** M1 前端交互。总图与详图使用相同模块编号；画布右侧也包含以下读图说明。

### 组件与状态

- Vue 组件展示登录、聊天、历史、文档与证据；Pinia 四个 store 持有前端状态。

### 问答流程

- 登录 token → Bearer 请求；本地 session_id → 提交 message。
- 按 SSE 事件更新发起会话的消息、进度、Trace 和 HITL 提示。
- 切换会话不改变原请求数组；停止使用 AbortController。

### 文档与边界

- 管理员上传后轮询 job，完成再刷新文档列表。
- 上传轮询在面板关闭后继续；删除轮询在组件卸载时停止。
- 前端不做 RAG 路由，也不承担服务器权限判断。

### 源码对应

- `frontend/src/App.vue`
- `frontend/src/stores/chat.ts`
- `frontend/src/stores/documents.ts`
