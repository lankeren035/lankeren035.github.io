# 图_4检索与Evidence构建

原生 Excalidraw 可编辑画布，基于 SuperMew-0.1.0。请使用 Obsidian 的 Excalidraw 视图打开。

**视图归属：** M5 检索专题。

### 输入与输出

- 输入 query 与 top_k；输出 docs 和检索 meta，尚未生成答案。

### 流程

- BGE query 编码后，Milvus 对 L3 执行 dense + BM25 + RRF。
- 候选经过两轮父块合并；Redis 优先、PG 回取父文本。
- 精排或回退排序先截 top_k，再过滤最低分，不回填。

### 异常

- Hybrid 链异常会重试 dense；精排失败回退原分排序。
- 最终可能少于 top_k 或为空；空证据由 M5 决策。

### 源码对应

- `backend/rag/utils.py`：`retrieve_documents()`
- `backend/rag/utils.py`：`_finalize_retrieval()`
- `backend/rag/utils.py`：`_auto_merge_candidates()`
- `backend/rag/utils.py`：`_rerank_documents()`
- `backend/indexing/milvus_client.py`：`hybrid_retrieve()`
- `backend/indexing/parent_chunk_store.py`：`get_documents_by_ids()`
