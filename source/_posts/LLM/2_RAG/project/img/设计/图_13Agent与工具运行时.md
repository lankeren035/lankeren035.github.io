# 图_13Agent与工具运行时

原生 Excalidraw 可编辑画布，基于 SuperMew-0.1.0。请使用 Obsidian 的 Excalidraw 视图打开。

**所属模块：** M4 Agent 与工具运行时。总图与详图使用相同模块编号；画布右侧也包含以下读图说明。

### 运行时

- MODEL 与 System Prompt 创建外层 Agent；绑定天气工具和请求专属知识工具。

### 流程

- MODEL 可直接回复，或发出 tool call；结果作为 ToolMessage 回到模型。
- 知识工具申请 ctx 一次额度，运行 RAG，并保存 Trace/恢复快照。
- service 对 HITL 结果改为澄清提示。

### 约束

- 知识调用次数有硬额度；收到知识结果后不再调工具主要由提示词约束。
- FAST/GRADE 分别用于笔记/规划/改写与评分，不是外层 Agent 的重复回路。

### 源码对应

- `backend/chat/runtime.py`：`create_agent_for_request()`
- `backend/tools/knowledge.py`：`make_search_knowledge_base()`
- `backend/tools/weather.py`：`get_current_weather()`
