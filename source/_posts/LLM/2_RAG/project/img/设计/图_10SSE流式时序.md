# 图_10SSE流式时序

原生 Excalidraw 可编辑画布，基于 SuperMew-0.1.0。请使用 Obsidian 的 Excalidraw 视图打开。

**视图归属：** M3 SSE 流式专题。

### 组成

- Agent worker、ctx 队列、SSE service 和前端读取器共同传递事件。

### 流程

- 进度由 ctx 线程安全入队；worker 把文本或错误入队。
- service 发送 content/rag_step/trace/hitl_request 等 JSON 事件。
- 内部 None 表示 worker 结束；SSE DONE 是另一种哨兵。

### 完成时序

- DONE 后才更新笔记并保存，前端继续读至 EOF。
- 用户停止只是取消路径，不保证外部调用立刻停止或 AI 已保存。

### 源码对应

- `backend/chat/service.py`：`chat_with_agent_stream()`
- `backend/chat/request_context.py`：`emit_rag_step()`
- `backend/api/routes/chat.py`：`chat_stream_endpoint()`
- `frontend/src/stores/chat.ts`
