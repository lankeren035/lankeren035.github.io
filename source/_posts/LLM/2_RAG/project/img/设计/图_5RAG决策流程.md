# 图_5RAG决策流程

原生 Excalidraw 可编辑画布，基于 SuperMew-0.1.0。请使用 Obsidian 的 Excalidraw 视图打开。

**视图归属：** M5 模块主图。

### 组成

- 入口分类、简单检索/评分/改写，以及复杂问题 Send 并行和 synthesis。

### 流程

- 明显简单问题由本地规则识别；其余由 FAST_MODEL 规划。
- 简单路径最多一次 Step-back 或 HyDE；空证据直接停止。
- 子问题仅 retrieve → grade，不各自生成答案或改写。

### 边界

- synthesis 只合并证据；最终答案在 M4/M3 生成。
- HITL route 结束图，跨轮状态由 M3 保存。

### 源码对应

- `backend/rag/pipeline.py`：`build_rag_graph()`
- `backend/rag/pipeline.py`：`_resolve_route()`
- `backend/rag/pipeline.py`：`rag_sub_agent()`
- `backend/rag/pipeline.py`：`synthesis()`
- `backend/rag/utils.py`：`rewrite_query_once()`
