# 1. 背景
- 构建一个基于 Langchain 的个人知识库助手。该助手通过高效的信息管理系统和强大的检索功能，为用户提供了一个可靠的信息获取平台。
- 结合大模型同时针对用户需求进行定制化开发，以实现对复杂信息的智能理解和精确回应。
- 主要集成了 RAG 技术，这是一种结合检索和生成的方法，能够在生成回答之前先从大量数据中检索相关信息，从而显著提高了回答的准确性和可靠性。
# 2. 环境
```shell
git clone https://github.com/logan-zou/Chat_with_Datawhale_langchain.git
cd Chat_with_Datawhale_langchain
# 创建 Conda 环境
conda create -n llm-universe python==3.9.0
# 激活 Conda 环境
conda activate llm-universe 
# 安装依赖项 #windows下删掉里面的uvloop
pip install -r requirements.txt

# 1. 先启动服务
# Linux 系统
cd serve
uvicorn api:app --reload
# Windows 系统
cd serve
python api.py

# 2. 再运行项目
cd llm-universe/serve
python run_gradio.py -model_name='chatglm_std' -embedding_model='m3e' -db_path='../../data_base/knowledge_db' -persist_path='../../data_base/vector_db'
```
