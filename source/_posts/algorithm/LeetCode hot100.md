# 1. 哈希
## 1.1 两数之和
`简单` 
给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** _`target`_  的那 **两个** 整数，并返回它们的数组下标。你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。你可以按任意顺序返回答案。

**示例 1：**
**输入：** nums = [2,7,11,15], target = 9
**输出：**[0,1]
**解释：** 因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。


**提示：**
- `2 <= nums.length <= 104`
- `-109 <= nums[i] <= 109`
- `-109 <= target <= 109`
- **只会存在一个有效答案**

**进阶：** 你可以想出一个时间复杂度小于 `O(n2)` 的算法吗？


```python
'''
1. [2,7,11,15]保存成 {2:0, 7:1 ,:2 11:3 ,15:4}
2. 遍历字典，对于2，  判断target-2是否在字典内
'''
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        map={}
        for i,x in enumerate(nums):
            if target-x in map:
                return [i,map[target-x]]
            else:
                map[x]=i
```

## 1.2 字母异位词分组
`中等`
> 给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

**示例 1:**
**输入:** strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
**输出:** \[["bat"],["nat","tan"],["ate","eat","tea"]]

**解释：**
- 在 strs 中没有字符串可以通过重新排列来形成 `"bat"`。
- 字符串 `"nat"` 和 `"tan"` 是字母异位词，因为它们可以重新排列以形成彼此。
- 字符串 `"ate"` ，`"eat"` 和 `"tea"` 是字母异位词，因为它们可以重新排列以形成彼此。
**提示：**

- `1 <= strs.length <= 104`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

```python
'''
1. 读取到一个字符串 eat
2. 将字符串排序：aet
3. 纳入字典：{aet:[eat] }
4. 下一个字符串排序后判断键是否存在，不存在则新建纳入，否则纳入已有列表
'''
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        map = defaultdict(list)
        for s in strs:
            sort_s = ''.join(sorted(s))
            map[sort_s].append(s)
        return list(map.values())
```

## 1.3 最长连续序列
`中等`

> 给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1：**
**输入：** nums = [100,4,200,1,3,2]
**输出：** 4
**解释：** 最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。


**提示：**
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

```python
'''
找最小起点
1. nums{100,4,200,1,3,2}
2. 遍历100，100纳入字典
3. 循环往后-1判断99是否在字典内，在则跳过（因为遍历到99的时候会统计100），不在则count+1
4. 循环往前+1判断101是否在，直到找停止
5. 前后搜索都停止则更新最优全局统计
'''
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        setnum = set(nums)
        res = 0
        for x in setnum:  #注意要遍历set不是list
            if x-1 in setnum:
                continue
            else:
                y = x+1
                while y in setnum:
                    y+=1
                res = max(res,y-x)
                if res*2 >= len(nums):
                    break
        return res
```

`简单`
>给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。**请注意** ，必须在不复制数组的情况下原地对数组进行操作。

**示例 1:**
**输入:** nums = `[0,1,0,3,12]`

**提示**:
- `1 <= nums.length <= 104`
- `-231 <= nums[i] <= 231 - 1`
1,2,0,3,12
```python
'''
1. anchor指向第一个0
2. cur指向当前位置
3. cur为0则往下走，不为0则启动交换
4. 交换后anchor往下走直到等于0
'''
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        anchor = 0
        for i,x in enumerate(nums):
            if nums[i] != 0:
                nums[anchor],nums[i] = nums[i],nums[anchor]
                anchor+=1
        
```

## 2.2 盛水最多的容器
> 给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。**说明：**你不能倾斜容器。

**示例 1：**

![](https://aliyun-lc-upload.oss-cn-hangzhou.aliyuncs.com/aliyun-lc-upload/uploads/2018/07/25/question_11.jpg)

**输入：**[1,8,6,2,5,4,8,3,7]
**输出：** 49 
**解释：** 图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。

**提示：**
- `n == height.length`
- `2 <= n <= 105`
- `0 <= height[i] <= 104`

```python
'''
1. 初始化左指针和右指针
2. 当前水量的宽可以知道，高取决于较低的那一个
3. 如果要找到盛水最多的，应该找一个比当前更多的，一直往上找
4. 因此只能移动较低的那个才能保证一直递增地找到更大面积
'''
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left = 0
        right = len(height)-1
        res = 0
        while(left<right):
            res=max( res, (right-left) * min(height[left],height[right]))            
            # 左边矮
            if height[left] < height[right]:
                # 左指针右移，知道找到一个更大值
                h = height[left]
                while left < right and height[left] <= h:
                    left+=1
            else:
                h = height[right]
                while left < right and height[right] <= h:
                    right-=1
        return res 
```

## 2.3 三数之和
`中等`
给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。**注意：**答案中不可以包含重复的三元组。

**示例 1：**

**输入：** nums = [-1,0,1,2,-1,-4]
**输出：**\[[-1,-1,2],[-1,0,1]]
**解释：**
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。


**提示：**
- `3 <= nums.length <= 3000`
- `-105 <= nums[i] <= 105`

```python
'''
1. 两数之和O(n)，这里三个数感觉O(n)做不了，往O(nlogn)想，因此可以排序
2. 先对数组排序，然后遍历取target， 双指针找两数之和
'''
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums_sort=sorted(nums)
        res = []
        for i,x in enumerate(nums_sort):
            left=i+1  #遍历这里面的最小值作为target
            right=len(nums)-1
            if i>0 and x==nums_sort[i-1]:
                continue #连续值
            while left < right:
                if nums_sort[right]*2 + x <0 or nums_sort[left]*2 + x >0:
                     break
                if nums_sort[right] + nums_sort[left] + x ==0:
                    res.append([x,nums_sort[right],nums_sort[left]])
                    while left<right and nums_sort[left]==nums_sort[left+1]:
                        left+=1
                    left+=1
                    while left<right and nums_sort[right]==nums_sort[right-1]:
                        right-=1
                    right-=1
                elif nums_sort[left] + nums_sort[right] + x <0:
                    left+=1
                else:
                    right-=1
        return res
            
```

`困难`
给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2018/10/22/rainwatertrap.png)

**输入：**height = [0,1,0,2,1,0,1,3,2,1,2,1]
**输出：**6
**解释：**上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。 


**提示：**

- `n == height.length`
- `1 <= n <= 2 * 104`
- `0 <= height[i] <= 105`

```python
'''
1. 左指针往右，碰到比自己小的，往结果加，碰到比自己大的，更新左边界
2. 右边同理，左右边界那边小就移动哪边
'''
class Solution:
    def trap(self, height: List[int]) -> int:
        n = len(height)
        left = 0
        right = n-1
        res = 0
        leftmax=height[left]
        rightmax=height[right]
        while left< right:
            leftmax=max(leftmax,height[left])
            rightmax=max(rightmax,height[right])
            if leftmax < rightmax:
                res+= leftmax-height[left]
                left+=1
            else:
                res+= rightmax-height[right]
                right-=1
        return res
```

## 3.1 无重复字符的最长子串
给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

**示例 1:**
**输入:** s = "abcabcbb"
**输出:** 3 
**解释:** 因为无重复字符的最长子串是 `"abc"`，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

**提示：**
- `0 <= s.length <= 5 * 104`
- `s` 由英文字母、数字、符号和空格组成
```python
'''
1. left和cur指针从左开始遍历
2. 初始化字典，每个字母：0
3. cur移动，读取的这个字符如果不在字典中，纳入
4. 读取的字符如果存在字典中，从left到第一个与cur重复的字符位置，统计长度，left走到cur同时删除路径上字典中的元素
'''
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        map=defaultdict(int)
        left=0
        res=0
        for i,x in enumerate(s):
            map[x]+=1
            while map[x]>1:
                map[s[left]]-=1
                left+=1
            res=max(res,i-left+1)
        return res
```

## 3.2 找到字符串中所有字母异位词
`中等`
给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**示例 1:**
**输入:** s = "cbaebabacd", p = "abc"
**输出:** [0,6]
**解释:**
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

**提示:**
- `1 <= s.length, p.length <= 3 * 104`
- `s` 和 `p` 仅包含小写字母

```python
'''
1. 定义两个计数器统计p中的各个字符数量以及s中工作空间的各个字符串数量
2. 遍历s取左右指针为工作空间，移动一次更新一次计数器
3. 如果两个计数器相等，发现一个答案，否则继续迭代，left处计数-1
'''
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        cont_s=Counter()
        cont_p=Counter(p)
        res=[]
        for i,x in enumerate(s):
            cont_s[x] += 1
            left=i+1-len(p)
            if left<0:
                continue
            if cont_s == cont_p:
                res.append(left)
            cont_s[s[left]]-=1
        return res
```

## 4.1 和为K的子数组

给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 _该数组中和为 `k` 的子数组的个数_ 。子数组是数组中元素的连续非空序列。

**示例 1：**
**输入：** nums = [1,1,1], k = 2
**输出：** 2


**提示：**
- `1 <= nums.length <= 2 * 104`
- `-1000 <= nums[i] <= 1000`
- `-107 <= k <= 107`

```python
'''
1. x1,     x2,     x3,     x4
2. 前缀和： 0，    0+x1,     0+x1+x2,     0+x1+x2+x3,     0+x1+x2+x3+x4
3. 前缀和做差 D(i,j) = sum(i,i+1,...j) 即为子数组和
4. 在前缀和序列中求两数之和
'''
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        summ=0
        map=defaultdict(int)
        map[0]=1 #表示s[i]整个前缀和=k的情况
        res=0
        for i, x in enumerate(nums):
            summ+=x #数字a
            res+=map[summ-k] # 前面遍历过的前缀和存在一个与当前前缀和做差得到K
            map[summ]+=1
        return res
```

## 4.3 最小覆盖子串
`困难`
给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 s 中的 **最短窗口 子串**，使得该子串包含 `t` 中的每一个字符（**包括重复字符**）。如果没有这样的子串，返回空字符串 `""`。测试用例保证答案唯一。

**示例 1：**
**输入：** s = "ADOBECODEBANC", t = "ABC"
**输出：**"BANC"
**解释：** 最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

**提示：**
- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 105`
- `s` 和 `t` 由英文字母组成

```python
'''
1. 子串用滑动窗口+计数器
2. 滑动窗口扩大，直到计数器完全覆盖子串计数器，说明找到了一个子串
3. 压缩子串，右移left指针，找到最短子串
'''
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        count_s = Counter()
        count_t=Counter(t)
        res=[-1,len(s)]
        left=0
        for i,x in enumerate(s):
            count_s[x]+=1
            while count_s >= count_t:
                if i-left < res[1] - res[0]:
                    res=[left,i]
                count_s[s[left]]-=1
                left+=1
        return '' if res[0] == -1 else s[res[0]:res[1]+1]

'''
1. 比较两个计数器时间复杂度太高，能不能将他缩短
2. 统计t中有几种不同字符，以及各自出现的次数
3. 统计窗口内有几种字符出现次数更多
'''
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        count_t=Counter(t)
        kind=len(count_t)
        res=[-1,len(s)]
        left=0
        ok_kind=0
        for i,x in enumerate(s):
            #移入一个，消掉一个
            count_t[x]-=1
            #窗口统计刚好大于t统计
            if count_t[x] == 0:
                ok_kind+=1
            while ok_kind == kind:
                if i-left < res[1] - res[0]:
                    res=[left,i]
                s_left=s[left]
                if count_t[s_left] == 0:
                    ok_kind-=1
                count_t[s_left]+=1
                left+=1
        return '' if res[0] == -1 else s[res[0]:res[1]+1]
                
```

```python
···
思路：对于pattern = abacad，text = ababacad 进行匹配
暴力做法：
    1. 取第0个位置，取出len(pattern)长度的一段，看看是否匹配： ababac != abacad，匹配失败
    2. 进入下一次迭代，取第1个位置开始，取出len(pattern)长度的一段，看看是否匹配：babaca!= abacad 也失败
    3. 第三次：abacad = abacad，匹配上了
    4. 每做一次比较，就需要len(pattern)的复杂度     
         
kmp算法：
    1. 从起点 0 匹配，已匹配 `"aba"` 后，在 `text[3]='b'` 与 `pattern[3]='c'` 处失配。
    2. 暴力算法的第二步其实没必要，因为pattern的第一个字符是a，而text[1]=b，显然不可能匹配上，能不能有什么办法直接跳过第二步呢？
    3. 观察第一步匹配上的部分，aba； 这个子串的首字符和尾字符是一样的，那么在匹配的时候假设text不动，我来滑动pattern，当第一步匹配失败之后，暴力做法是讲pattern滑动一下，然后判断，有没有办法能直接滑动两下呢？因为滑动两下就能直接匹配上末尾这个a了。
    4. kmp算法的核心是先分析pattern字符串，判断当在第i个位置匹配失败后应该滑动几次。上面这个例子假设在第四个字符这里匹配失败了：abab!=abac， 根据已经匹配的经验：'aba'，应该直接滑动两次。
    5. 如何获得这个经验呢？这需要我们提前准备好一个数组，用来判断当第i步匹配失败后滑动几步。本质上是在求这样一个问题：对于pattern，遍历每个长度的p[0:i]，找到这个串的最长相等前后缀的长度。这就是在位置i匹配失败后应该滑动的步长。
    6. 对于这个例子，他的经验数组pi=[0,0,1,0,1,0],解释：
       a : 没有前后缀（前后缀不包含最后或第一个字母） -> 0
       ab : 前缀a,  后缀b；不等，     -> 0
       aba: 前缀：a, ab;  后缀：a,ab   ->最长相等前后缀（a）长度是1
       abac  -> 0
       ababa -> 1
       abacad -> 0
    7. 得到上面的数组之后，从头遍历做匹配，如果在位置pattern[i]位置匹配失败，就滑动p[i]次。

def kmp_search(text: str, pattern: str) -> List[int]:
    m = len(pattern)
    pi = [0]*m
    cnt = 0
    for i in raneg(1,m): #求p[0:i+1]的最长相等前后缀的长度
        # cnt表示pi[i-1]
        b = pattern[i]
        while cnt and pattern[cnt]!=b:
            # pi[i]无法在pi[i-1]上加1，那么p[0:i+1]的最长相等前后缀的长度需要回退，假设回退到
            cnt = pi[cnt-1]
        if pattern[cnt] ==b: #p[:i]的最长前后缀长度是cnt，这里pattern[cnt]就表示往最长前后缀的前缀后面取一个， b表示最长前后缀的后缀往后再取一个，如果这二者相等，说明pi[i]可以再p[i-1]基础上加1。否则就是进入上面的循环。
            cnt+=1
        pi[i]=cnt
    pos = []
    cnt = 0 #text 后缀匹配 pattern 前缀多长
    for i, b in enumerate(text):
        while cnt and pattern[cnt] != b:
            cnt = pi[cnt - 1]
        if pattern[cnt] == b:
            cnt += 1
        if cnt == len(pattern):
            pos.append(i - m + 1)
            cnt = pi[cnt - 1]
    return pos
```

```python
'''
1. 子串问题用前缀和
2. 连续子数组和就是两个前缀和相减
3. 只要我知道遍历到当前位置时，历史前缀和中哪个最小，就可以知道当前时刻的答案
'''
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        res = nums[0]
        summ=nums[0]
        min_summ=nums[0]
        for i,x in enumerate(nums):
            summ+=x
            res = max(res, summ-min_summ)
            min_summ = min(min_summ, summ)
        return res
```

## 5.2 合并区间
`中等`
以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]` 。请你合并所有重叠的区间，并返回 _一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间_ 。

**示例 1：**
**输入：** intervals = \[[1,3],[2,6],[8,10],[15,18]]
**输出：** \[[1,6],[8,10],[15,18]]
**解释：** 区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].


**提示：**
- `1 <= intervals.length <= 104`
- `intervals[i].length == 2`
- `0 <= starti <= endi <= 104`

```python
'''
1. 先按照左边元素排序
2. 遍历到一个新元素时，判断：左大于上一个的右：没重叠，纳入区间，更新右边界
3. 左小于上一个的右：说明有重叠，继续判断
4. 右小于上一个的右：包含，不更新右界
5. 右大于上一个的右，交叉，融合区间，更新右界
'''
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort()
        res = []
        for x in intervals:
            if res and x[0] <= res[-1][1]:
                res[-1][1]= max(x[1],res[-1][1])
            else:
                res.append(x)
        return res
        
        
        
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        mx = max(p[1] for p in intervals)

        diff = [0] * (mx * 2 + 2)
        for start, end in intervals:
            # 把区间 [start*2, end*2] 增加 1
            diff[start * 2] += 1
            diff[end * 2 + 1] -= 1

        ans = []
        sum_d = 0
        start = -1  # -1 表示尚未遇到合并后的区间左端点
        for i, d in enumerate(diff):
            sum_d += d  # 计算 diff 的前缀和
            if sum_d > 0:
                if start < 0:
                    start = i  # 合并后的区间左端点
            elif start >= 0:
                # i-1 是合并后的区间右端点
                # 由于乘 2 操作，区间左右端点都是偶数，所以 i-1 是偶数，i 是奇数，(i-1)/2 == floor(i/2)
                ans.append([start // 2, i // 2])
                start = -1
        # 注：最后一轮循环 sum_d == 0，我们不会漏掉最后一个区间
        return ans
```

```python
1. 数组长度为n，那么这个数的范围就是1 ~ n+1
2. 先将负数赋值成n+1，然后遍历数组
3. 如果当前数字的绝对值在 1 ~ n， 说明他是一个需要考虑的数，将他应该在的位置进行标记（坐在这个位置的数变成负数）
4. 遍历完成之后合法位置部分的数应该都是负数，只要这个位置上的数字为正数就说明他是第一个不存在的数字
'''
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)
        for i in range(n):
            while 0<nums[i]<=n and nums[i] != nums[nums[i]-1]:
                j = nums[i] - 1
                nums[i],nums[j] = nums[j],nums[i]
        for i,x in enumerate(nums):
            if x != i+1:
                return i+1
        return n+1
        
```

- `1 <= m, n <= 10`
- `-100 <= matrix[i][j] <= 100`

```python
1. 定义四个方向顺序一次遍历，从当前点使用这个方向，如果使用后越界就尝试下一个方向
'''
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        direction=((0,1),(1,0),(0,-1),(-1,0))
        cur_dir=0
        m=len(matrix)
        n=len(matrix[0])
        i,j=0,0
        res=[]
        for _ in range(m*n):
            res.append(matrix[i][j])
            matrix[i][j] = None
            ii,jj = i+direction[cur_dir][0] , j+direction[cur_dir][1]
            if ii<0 or ii>=m or jj<0 or jj>=n or matrix[ii][jj] is None:
                cur_dir = (cur_dir+1) % 4
            i,j = i+direction[cur_dir][0] , j+direction[cur_dir][1]
        return res
```

**提示：**
- 链表中节点的数目范围在范围 `[0, 104]` 内

```python
'''
1. 假设head到入口长度：a ; 相遇时slow走的路程为: b， 环长：c； fast比slow夺走了k圈：
2. slow路程： b; fast路程： 2b
3. 2b - b = kc
   b = kc
4. 慢指针从入环口开始，走了 b-a步到达相遇点，走了 kc-a步到达相遇点
5. 再走a步就在环内走了 kc步，肯定到了相交点
'''
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow=fast=head
        while(fast and fast.next):
            fast = fast.next.next
            slow = slow.next
            if fast is slow:
                while slow is not head:
                    head=head.next
                    slow=slow.next
                return slow
        return None
```

```python
1. 遍历链表得到长度
2. 循环，每次处理k个反转，长度-=k
'''
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        count = 0
        cur = head
        while(cur):
            cur = cur.next
            count+=1
        res = pre = ListNode(next=head)
        left = pre
        cur = head
        for i in range(count // k):
            for j in range(0,k):
                nxt = cur.next
                cur.next=left
                left=cur
                cur = nxt
            nxt =  pre.next  
            nxt.next = cur
            pre.next = left
            pre = nxt
        return res.next
```

## 7.14 LRU 缓存
`中等`
请你设计并实现一个满足  [LRU (最近最少使用) 缓存](https://baike.baidu.com/item/LRU) 约束的数据结构。实现 `LRUCache` 类：
- `LRUCache(int capacity)` 以 **正整数** 作为容量 `capacity` 初始化 LRU 缓存
- `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1` 。
- `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value` ；如果不存在，则向缓存中插入该组 `key-value` 。如果插入操作导致关键字数量超过 `capacity` ，则应该 **逐出** 最久未使用的关键字。
函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

**示例：**
**输入**
["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]
**输出**
[null, null, null, 1, null, -1, null, -1, 3, 4]

**解释**
LRUCache lRUCache = new LRUCache(2);
lRUCache.put(1, 1); // 缓存是 {1=1}
lRUCache.put(2, 2); // 缓存是 {1=1, 2=2}
lRUCache.get(1);    // 返回 1
lRUCache.put(3, 3); // 该操作会使得关键字 2 作废，缓存是 {1=1, 3=3}
lRUCache.get(2);    // 返回 -1 (未找到)
lRUCache.put(4, 4); // 该操作会使得关键字 1 作废，缓存是 {4=4, 3=3}
lRUCache.get(1);    // 返回 -1 (未找到)
lRUCache.get(3);    // 返回 3
lRUCache.get(4);    // 返回 4

**提示：**
- `1 <= capacity <= 3000`
- `0 <= key <= 10000`
- `0 <= value <= 105`
- 最多调用 `2 * 105` 次 `get` 和 `put`

```python
'''
1. 需要两个对象：一个Node，一个LRUCache
2. Node有key和value
3. LRUCache里面存储Node组成的链表
4. LRUCache需要能get，因此需要有一个哈希表
5. LRUCache需要能put，因此需要头插以及删除
6. 为了快速删除末尾元素可以使用双向链表
'''
class Node:
    __slots__ = 'prev', 'next', 'key', 'value'
    def __init__(self,key=0,val=0,next=None,pre=None):
        self.key=key
        self.val =val
        self.next =next
        self.pre=pre
class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.dummy = Node()
        self.dummy.next = self.dummy
        self.dummy.prev = self.dummy
        self.map = {}
    def get(self, key: int) -> int:
        # 存在则返回他的value，否则返回-1， 访问一次就要将他更新到队头
        if key in self.map:
            node = self.map[key]
            self.remove(node)
            self.push(node)
            return node.value
        else:
            return -1
    def put(self, key: int, value: int) -> None:
        if key in self.map:
            node = self.map[key]
            node.value = value
            self.remove(node)
            self.push(node)
        else:
            node = self.map[key] = Node(key, value)
            self.push(node)
            if len(self.map) > self.capacity:
                finalnode = self.dummy.prev
                del self.map[finalnode.key]
                self.remove(finalnode)
    def remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev
    def push(self, node):
        node.next = self.dummy.next
        node.prev = self.dummy
        self.dummy.next = node
        node.next.prev = node
```

```python
class Solution:
```

```python
        if root is None:
            return 0
        depleft = self.maxDepth(root.left)
        depright = self.maxDepth(root.right)
        return max(depleft, depright)+1

        res = 0
        def dfs(root, depth):
            if root is None:
                return
            dfs(root.left, depth+1)
```

## 8.5 二叉树的直径
`简单`
给你一棵二叉树的根节点，返回该树的 **直径** 。二叉树的 **直径** 是指树中任意两个节点之间最长路径的 **长度** 。这条路径可能经过也可能不经过根节点 `root` 。两节点之间路径的 **长度** 由它们之间边数表示。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/03/06/diamtree.jpg)

**输入：** root = [1,2,3,4,5]
**输出：** 3
**解释：** 3 ，取路径 [4,2,1,3] 或 [5,2,1,3] 的长度。


**提示：**
- 树中节点数目在范围 `[1, 104]` 内
- `-100 <= Node.val <= 100`
```python
'''
1. 定义从根节点到叶子节点的长度为链
2. 对于一个root，取左边的最长链+右边的最长链 等于root的最大直径
3. 由于最大直径肯定是两个叶子节点之间的距离，两个节点肯定会相交于同一个最近的root
4. 遍历所有root就可以迭代最大半径况
'''
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        res = 0    
        def dfs(root):
            if root is None:
                return 0
            left_depth = dfs(root.left)
            right_depth = dfs(root.right)
            nonlocal res
            res = max(res, left_depth+right_depth)
            return max(left_depth, right_depth)+1

        dfs(root)
        return res
            
            
```

```python
                    tmp.append(node.val)
                    q.append(node.left)
                    q.append(node.right)
            if tmp:
                res.append(tmp)
        return res
```

```python
'''
1. 中序遍历，判断当前节点是否一直大于pre
2. 先序遍历，root在一个范围内，往左走，下界不变，上界更新为root。 往右走，下界变为root，上界不变
3. 后序遍历，先判断左子树合法，再判断右子树合法，遍历的时候取出最大最小值，当前点大于left的max，小于right的min. 可以返回一个区间以判断，同时根据区间判断是否合法。  当遍历到None时为了保证上层一定合法， left_max取-inf， right_min取inf， 因此None返回 inf,-inf
'''
class Solution:

    res = True
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def dfs(root):
            if root is None:
                return
            dfs(root.left)
            if root.val <= self.pre:
                self.res = False
            self.pre = root.val
            dfs(root.right)
        dfs(root)
        return self.res

    def isValidBST(self, root: Optional[TreeNode], left=-inf, right=inf) -> bool:
        if root is None:
            return True
        x = root.val 
        return left < x < right and self.isValidBST(root.left, left, x) and self.isValidBST(root.right, x, right)
        
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def dfs(root):
            if root is None:
                return inf, -inf
            lmin,lmax = dfs(root.left)
            rmin,rmax = dfs(root.right)
            x = root.val
            if lmax < x < rmin:
                return min(lmin, x), max(rmax, x)
            else:
```

```python
'''
1. 层序遍历，每次迭代取最后一个
2. dfs，但是先递归右边，再递归左边，由于是右优先，因此没到一个新的深度时，第一个遍历的就是最右的
'''
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        queue = [root]
        res = []
        while queue:
            n = len(queue)
            for i in range(n):
                node = queue.pop(0)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            res.append(node.val)
        return res
        
class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        res = []
        def dfs(root,depth):
            if root is None:
                return
            if depth == len(res): #首次达到该深度,res递增
                res.append(root.val)
            dfs(root.right, depth+1)
            dfs(root.left, depth+1)
        dfs(root,0)
        return res
```

## 8.12 从前序与中序遍历序列构造二叉树
`中等`
给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的**先序遍历**， `inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

**示例 1:**
![](https://assets.leetcode.com/uploads/2021/02/19/tree.jpg)

**输入**:  preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
**输出:** [3,9,20,null,null,15,7]


**提示:**
- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均 **无重复** 元素
- `inorder` 均出现在 `preorder`
- `preorder` **保证** 为二叉树的前序遍历序列
- `inorder` **保证** 为二叉树的中序遍历序列
```python
'''
1. 取出左子树，右子树的 前序中序数组，递归得到左子树右子树，然后与根拼接
2. 优化：哈希存储索引，递归传递索引
'''
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if not preorder:
            return
        rootval = preorder[0]
        index = inorder.index(rootval)
        # 前序遍历中从1到 1+index-1为左，   1+index 到最后为右边
        # 中序遍历从0 到 index-1 为左，   index+1 到最后为右边
        leftroot = self.buildTree(preorder[1:index+1], inorder[:index])
        rightroot = self.buildTree(preorder[index+1:], inorder[index+1:])
        return TreeNode(val=rootval, left=leftroot, right=rightroot)
        
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        nodemap = {x:i for i,x in enumerate(inorder)}
        n = len(preorder)
        def dfs(prel, prer, inl, inr):
            if prel > prer:
                return
            rootval = preorder[prel]
            rootindex = nodemap[rootval]
            leftnum = rootindex - inl
            # 前序遍历： 左：prel+1, prel+leftnum   右： prel+leftnum+1:
            # 中序遍历： 左：inl, rootindex-1  右：rootindex+1:
            leftnode = dfs(prel+1, prel+leftnum,inl, rootindex-1)
            rightnode = dfs(prel+leftnum+1,prer, rootindex+1, inr)
            return TreeNode(rootval, leftnode,rightnode)
        return dfs(0,n-1,0,n-1)
            
```

`中等`

**解释：** 和等于 8 的路径有 3 条，如图所示。

- `-109 <= Node.val <= 109` 
- `-1000 <= targetSum <= 1000`
```python
'''
1. 求子串和用前缀和
2. 有几个叶子节点就有几个序列，遍历这些序列求前缀和
3. 递归时累计一条链的前缀和（类似最大深度），递归这条链的过程中用哈希表记录出现了哪些前缀和，出现了几次。
4. 每一个节点都可能是子序列的尾，以当前节点为尾，当前前缀和为a， 历史前缀和记录情况为b，寻找匹配的前缀和记录了多少次。
'''
class Solution:
    res = 0
    accum = defaultdict(int)
    accum[0] = 1 #链长为target时，前缀和直接等于target，类似于前缀和前面记录0
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        def dfs(root, summ):
            if root is None:
                return
            cur_summ = summ+root.val
            self.res += self.accum[cur_summ-targetSum]
            self.accum[cur_summ] +=1            
            dfs(root.left, cur_summ)
            dfs(root.right, cur_summ)
            self.accum[cur_summ] -= 1
        dfs(root,0)
        return self.res
        
```

![](https://assets.leetcode.com/uploads/2020/10/13/exx1.jpg)

**输出：** 6

**提示：**

- `-1000 <= Node.val <= 1000`
```python
'''
1. 观察发现，任意一条路径可以由同一个root的两条链组成
2. 遍历每个root，计算他的左右最大链长，相加得到当前root的解
3. 当最大链长是负数时，返回0表示不选这条链
'''
class Solution:

    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        def dfs(root):
            if root is None:
                return 0
            leftres = dfs(root.left)
            rightres = dfs(root.right)
            self.res = max(self.res,  root.val+leftres+rightres)
            return max( max(leftres, rightres) + root.val , 0 )
        dfs(root)
        return self.res
```

## 9.2 腐烂的橘子
`中等`
在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三个值之一：
- 值 `0` 代表空单元格；
- 值 `1` 代表新鲜橘子；
- 值 `2` 代表腐烂的橘子。
每分钟，腐烂的橘子 **周围 4 个方向上相邻** 的新鲜橘子都会腐烂。
返回 _直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 `-1`_ 。

**示例 1：**

**![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/02/16/oranges.png)**

**输出：** 4

- `n == grid[i].length`

- `grid[i][j]` 仅为 `0`、`1` 或 `2`
```python
'''
1. 本题不能想岛屿一样递归记录最大深度，因为如果左右有两个烂橘子，他们会同时扩散
2. 应该用bfs，先记录下来所有烂橘子的位置，以及好橘子的个数
3. 模拟遍历，遍历一次就从队列剔除一个，然后将周围的好橘子变烂进入队列
'''
class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        q = []
        fresh = 0
        minute = 0
        m,n = len(grid),len(grid[0])
        for i,x in enumerate(grid):
            for j,y in enumerate(x):
                if y == 1:
                    fresh+=1
                if y == 2:
                    q.append((i,j))
        while(q and fresh):
            tmp = q
            q = []
            minute += 1
            for i,j in tmp:
                for x,y in (i+1,j),(i-1,j),(i,j+1),(i,j-1):
                        fresh -= 1
                        grid[x][y] = 2
                        q.append((x,y))
        return -1 if fresh else minute
                    
            
```

```python
1. 判断图中是否有环，用dfs，标记每个点的三种状态：0，1，2： 未访问，正在访问，访问过
'''
class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        graph = [[] for _ in range(numCourses)]
        for a,b in prerequisites:
            graph[a].append(b)
        states = [0] * numCourses
        def dfs(root):
            states[root]=1
            for x in graph[root]:
                if states[x] == 1 or states[x] == 0  and dfs(x):
                    return True
            states[root] = 2
            return False
        for i in range(numCourses):
            if states[i] == 0 and dfs(i):
                return False
        return True
```
## 9.4 实现 Trie (前缀树)
`中等`
**[Trie](https://baike.baidu.com/item/%E5%AD%97%E5%85%B8%E6%A0%91/9825209?fr=aladdin)**（发音类似 "try"）或者说 **前缀树** 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。请你实现 Trie 类：
- `Trie()` 初始化前缀树对象。
- `void insert(String word)` 向前缀树中插入字符串 `word` 。
- `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`（即，在检索之前已经插入）；否则，返回 `false` 。
- `boolean startsWith(String prefix)` 如果之前已经插入的字符串 `word` 的前缀之一为 `prefix` ，返回 `true` ；否则，返回 `false` 。

**示例：**

**输入**
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
**输出**
[null, null, true, false, true, null, true]

**解释**
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 True
trie.search("app");     // 返回 False
trie.startsWith("app"); // 返回 True
trie.insert("app");
trie.search("app");     // 返回 True

**提示：**
- `1 <= word.length, prefix.length <= 2000`
- `word` 和 `prefix` 仅由小写英文字母组成
- `insert`、`search` 和 `startsWith` 调用次数 **总计** 不超过 `3 * 104` 次
```python
'''
1. 26叉树，每个树标记是否为终止节点
'''
class Node:
    __slots__ = 'son', 'isend'
    def __init__(self):
        self.son = {}
        self.isend = False
class Trie:
    def __init__(self):
        self.root = Node()
    def insert(self, word: str) -> None:
        cur = self.root
        for s in word:
            if s not in cur.son:
                cur.son[s] = Node()
            cur = cur.son[s]
        cur.isend=True
    def search(self, word: str) -> bool:
        cur = self.root
        for s in word:
            if s not in cur.son:
                return False
            cur = cur.son[s]
        return cur.isend == True
    def startsWith(self, prefix: str) -> bool:
        cur = self.root
        for s in prefix:
            if s not in cur.son:
                return False
            cur = cur.son[s]
        return True
```

```python
1. 每个数字可重复选择，累计和大于target就返回
2. 先排序再找
3. 完全背包进一步确定可行范围再递归
'''
class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        res = []
        path = []
        n = len(candidates)
        def dfs(i, summ):
            if i== n or summ >= target:
                if summ == target:
                    res.append(path.copy())
            else:
                dfs(i+1, summ)
                path.append(candidates[i])
                dfs(i, summ+candidates[i])
                path.pop()
        dfs(0,0)
        return res

        res = []

        n = len(candidates)
        candidates.sort()
        def dfs(i, left):
            if left == 0:
                res.append(path.copy())
                return
            if i==n or left < candidates[i]:
                return

            dfs(i+1, left )
            path.append(candidates[i])
            dfs(i, left - candidates[i])

        dfs(0,target)
```

**输出：** true

**提示：**

- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

**进阶：** 你可以使用搜索剪枝的技术来优化解决方案，使其在 `board` 更大的情况下可以更快解决问题？

```python
'''
1. 遍历每个点进行dfs
2. 优化1： 统计字母数量，如果字母储备不够直接return
3. 首尾看看哪个字符出现的更多，判断要不要翻转
'''
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        count = Counter([c for row in board for c in row])
        if Counter(word) > count:
            return False
        if count[word[0]] > count[word[-1]]:
            word=word[::-1]
    
        m,n = len(board), len(board[0])
        lenword = len(word)
        def dfs(i,j,k):
            if k == lenword:
                return True
            if i<0 or j<0 or i>=m or j>= n:
                return False
            if board[i][j] == word[k]:
                board[i][j] = None
                for x,y in (i+1,j),(i-1,j),(i,j-1),(i,j+1):
                    if dfs(x,y,k+1):
                        return True
                board[i][j] = word[k]
            return False
        return any(dfs(i, j, 0) for i in range(m) for j in range(n))
```

整数数组 `nums` 按升序排列，数组中的值 **互不相同** 。在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了 **向左旋转**，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标 **从 0 开始** 计数）。例如， `[0,1,2,4,5,6,7]` 下标 `3` 上向左旋转后可能变为 `[4,5,6,7,0,1,2]` 。给你 **旋转后** 的数组 `nums` 和一个整数 `target` ，如果 `nums` 中存在这个目标值 `target` ，则返回它的下标，否则返回 `-1` 。你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**
**输入：** nums = [4,5,6,7,0,1,2], target = 0
**输出：** 4


**提示：**
- `1 <= nums.length <= 5000`
- `-104 <= nums[i] <= 104`
- `nums` 中的每个值都 **独一无二**
- 题目数据保证 `nums` 在预先未知的某个下标上进行了旋转
- `-104 <= target <= 104`
```python
'''
1. 二分然后分类讨论，先判断target在哪段，然后判断mid在哪段
2. target < end    mid < end   : 都在右侧，用二分
3. target <= end    mid > end   :  target在右侧，更新left
4. target > end    mid < end   : target在左侧，更新right
5. target > end    mid > end   : 都在左侧，二分
'''
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums)-1
        
        while(left<=right):
            mid = (left+right) // 2
            x = nums[mid]
            end = nums[-1]
            if target<=end<x:
                left = mid+1
            elif x <= end < target:
                right = mid - 1
            elif x>target:
                right = mid - 1
            else:
                left = mid+1
        return right if nums[right] == target else -1
```
## 11.5 寻找旋转排序数组中的最小值
`中等`
已知一个长度为 `n` 的数组，预先按照升序排列，经由 `1` 到 `n` 次 **旋转** 后，得到输入数组。例如，原数组 `nums = [0,1,2,4,5,6,7]` 在变化后可能得到：
- 若旋转 `4` 次，则可以得到 `[4,5,6,7,0,1,2]`
- 若旋转 `7` 次，则可以得到 `[0,1,2,4,5,6,7]`
注意，数组 `[a[0], a[1], a[2], ..., a[n-1]]` **旋转一次** 的结果为数组 `[a[n-1], a[0], a[1], a[2], ..., a[n-2]]` 。
给你一个元素值 **互不相同** 的数组 `nums` ，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的 **最小元素** 。
你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**
**输入：** nums = [3,4,5,1,2]
**输出：** 1
**解释：** 原数组为 [1,2,3,4,5] ，旋转 3 次得到输入数组。

**提示：**
- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的所有整数 **互不相同**
- `nums` 原来是一个升序排序的数组，并进行了 `1` 至 `n` 次旋转
```python
'''
1. left > end  ,  mid > end:  右移
2. lfet > end  ,  mid <= end:  左移
3. left <= end  ,  mid <= end:  左移
'''
class Solution:
    def findMin(self, nums: List[int]) -> int:
        left,right = 0,len(nums)-1
        while(left<=right):
            mid = (left+right) // 2
            if nums[mid] > nums[-1]:
                left = mid+1
            else:
                right = mid-1
        return nums[left]
```

```python
        mapp = {')':'(', ']':'[', '}':'{'}
```

minStack.pop();

**提示：**

- `push`, `pop`, `top`, and `getMin`最多被调用 `3 * 104` 次
```python
'''
1. 栈内存元组，val以及当前为止的最小值
2. 栈内存一个元素，存储val与当前最小值的插值，实时更新当前最小值
   
'''
class MinStack:
    def __init__(self):
        self.stack = [(0,inf)]
    def push(self, value: int) -> None:
        self.stack.append((value, min(value, self.stack[-1][1])))
    def pop(self) -> None:
        self.stack.pop()
    def top(self) -> int:
        return self.stack[-1][0]
    def getMin(self) -> int:
        return self.stack[-1][1]
        
class MinStack:
    def __init__(self):
        self.stack = [0]
        self.min = inf
    def push(self, value: int) -> None:
        self.stack.append(value - self.min)
        self.min = min(self.min, value)
    def pop(self) -> None:
        top = self.stack.pop()
        if top < 0:
            self.min -= top
    def top(self) -> int:
        top = self.stack[-1]
        if top <0:
            return self.min
        else:
            return top + self.min
    def getMin(self) -> int:
        return self.min
```

`中等`

- `1 <= temperatures.length <= 105`
- `30 <= temperatures[i] <= 100`

```python
'''
1. 遍历数组，如果当前数字比top小：  纳入下标
2. 如果当前数字比top大： 更新top下标的答案，pop，纳入下标
'''
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        stack = []
        res = [0] * len(temperatures)
        for i,x in enumerate(temperatures):
            while stack and x > stack[-1][1]:
                top = stack.pop()[0]
                res[top] = i - top
            stack.append((i,x))
        return res
```

```python
'''

1. 如果该元素小于top，说明右边无法扩展了，要给出top元素的答卷

class Solution:

                left = stack[-1]
                res = max(res, (i-left-1)*heights[top])

        return res
```

```python
'''
1. 二分加快排
'''
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        left,right = 0, len(nums)-1
        target = right-k+1
        while(left <= right):
            mid = (left+right) // 2
            nums[left],nums[mid] = nums[mid],nums[left]
            l,r = left+1,right
            while l<=r:
                while l<=r and nums[l] < nums[left]:
                    l+=1
                while l<=r and nums[r] > nums[left]:
                    r-=1
                if l>r:
                    break
                nums[l], nums[r] = nums[r], nums[l]
                l+=1
                r-=1
            nums[left],nums[r] = nums[r],nums[left]                    
            if r == target:
                return nums[r]
            elif r < target:
                left = r+1
            else:
                right = r-1
```

```python
'''
1. 括号匹配问题用栈，读到 （就把他的下标入栈
   读到）就pop，pop之后如果空了，说明当前这个右括号没人跟他匹配了（栈底先放一个-1），更新左边界。pop之后如果没空，说明目前还在连续匹配，更新最大值。这里每次遍历i表示以s[i]结尾的最长长度
'''
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stack = [-1]
        res = 0
        count = 0
        for i,c in enumerate(s):
            if c == '(':
                stack.append(i)
            else:
                stack.pop()
                if stack:
                    # pop之后stack不空，更新结果,有多少个连续数字
                    res = max(res, i-stack[-1])
                else:
                    # pop之后空了，重新标记开头
                    stack.append(i)
        res = max(res,count)
        return res
        
'''
1. 用一个left和right来记录左右括号出现的次数
2. 如果 left = right，说明匹配成功，更新一下答案
   如果left > right, 说明还在匹配
   如果left < right, 说明断了，刷新left,right
   
   关键是left > right的时候怎么判断， 他可能是 (((()) res=4, 还有一个左括号待匹配。也可能是(()(()  res=2。 可以把他反转再遍历一次
'''
class Solution:
    def f(self, s, pattern):
        left,right,res = 0,0,0
        for c in s:
            if c == pattern:
                left+=1
            else:
                right += 1
            if left == right:
                res = max(res, right*2)
            elif left < right:
                left= right= 0
        return res
    def longestValidParentheses(self, s: str) -> int:
        return max(self.f(s,'('), self.f(reversed(s), ')') )
        
'''
dp版本：
如果： s[i]=‘)’ 且 s[i−1]=‘(’，也就是字符串形如 “……()”，我们可以推出：
        dp[i]=dp[i−2]+2
如果： s[i]=‘)’ 且 s[i−1]=‘)’，也就是字符串形如 “……))”，我们可以推出：
        如果 s[i−dp[i−1]−1]=‘(’，那么  dp[i]=dp[i−1]+dp[i−dp[i−1]−2]+2
'''
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        f = [0]*(len(s)+1)
        for i,c in enumerate(s):
            if c ==')':
                if i>0 and s[i-1] == '(':
                    f[i+1] = 2+f[i-1]
                elif i>0 and s[i-1]==')':
                    pos = i-f[i]-1
                    if pos>=0 and s[pos] == '(':
                        f[i+1] = f[pos]+f[i]+2
        return max(f)
```

## 17.4 下一个排列
`中等`

整数数组的一个 **排列** 就是将其所有成员以序列或线性顺序排列。
- 例如，`arr = [1,2,3]`，以下这些都可以视作 `arr` 的排列：`[1,2,3]`、`[1,3,2]`、`[3,1,2]`、`[2,3,1]`。
整数数组的 **下一个排列** 是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典顺序从小到大排列在一个容器中，那么数组的下一个排列就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列，即其元素按升序排列。
- 例如，`arr = [1,2,3]` 的下一个排列是 `[1,3,2]`。
- 类似地，`arr = [2,3,1]` 的下一个排列是 `[3,1,2]`。
- 而 `arr = [3,2,1]` 的下一个排列是 `[1,2,3]`，因为 `[3,2,1]` 不存在一个字典序更大的排列。
给你一个整数数组 `nums`，找出 `nums` 的下一个排列。必须 **原地** 修改，只允许使用额外常数空间。

**示例 1：**
**输入：** nums = [1,2,3]
**输出：** [1,3,2]

**提示：**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 100`

```python
'''
1. 下一个排列数值更大，但是尽量增加的幅度最小，先考虑个位和十位能不能换，如果个位大于十位，将最小值放到十位： xx59 -> xx95。  如果个位小于十位，没找到证据，再看百位，如果百位的数字比个位或十位小，说明可以把百位调大从而使得整体值变大  xx395->xx539  xx695->xx956
   总结规律：从右往左找递增台阶那一阶降了：  降升升升
           找到第一个降级的台阶a，然后再从右往左扫描第一个大于它的b
           ab换位，这样就保证了最小限度的增大最低的位置
           换位之后的的后缀是降序的，把他倒序从而保证其最小
    特殊情况，最大值的那个就跳过交换
'''
class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        down = len(nums)-2
        while(down>=0 and nums[down]>=nums[down+1]):
            down-=1
        if down>=0:
            target = len(nums)-1
            while(nums[target]<=nums[down]):
                target-=1
            nums[target],nums[down] = nums[down],nums[target]
        down+=1
        up=len(nums)-1
        while(down < up):
            nums[down],nums[up] = nums[up],nums[down]
            down+=1
            up-=1
```
## 17.5 寻找重复数
`中等`

给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1,n]` 范围内（包括 `1` 和 `n`），可知至少存在一个重复的整数。假设 `nums` 只有 **一个重复的整数**，返回这个重复的数。你设计的解决方案必须 **不修改** 数组 `nums` 且只用常量级 `O(1)` 的额外空间。

**示例 1：**
**输入：** nums = [1,3,4,2,2]
**输出：** 2

**提示：**
- `1 <= n <= 10^5`
- `nums.length == n + 1`
- `1 <= nums[i] <= n`
- `nums` 中只有一个整数出现两次或多次，其余整数均只出现一次

**进阶：**
- 如何证明 `nums` 中至少存在一个重复的数字？
- 你可以设计一个线性级时间复杂度 `O(n)` 的解决方案吗？

```python
'''
1. 不断交换元素直到0位置上放x  x位置上也放x；如果不满足条件就交换，每次交换换过来的数字不同，因此能遍历得到答案
2. 从图的角度来看，将数组转换成i->nums[i]的图。  
    13422变成 0->1->3->2->4->2
    由于只有一个重复元素，因此只有一个节点存在多个入度
    由于nums[i] > 0，因此 0没有入度只有出度
    由于1<=nums[i]<=n，因此每个nums[i]都能变成i，每个节点都有出度
    在0这条链上，由于每个节点都有出度，0又没有入度，因此肯定有一个点入度大于1，这就相当于链表有环了
'''
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        while(nums[0] != nums[nums[0]]):
            i=nums[0]
            nums[0], nums[i] = nums[i],nums[0]
        return nums[0]
        
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow=fast=0
        while(True):
            slow=nums[slow]
            fast=nums[nums[fast]]
            if slow == fast:
                break
        target=0
        while(target!=slow):
            slow=nums[slow]
            target=nums[target]
        return target
```
